gateway.image_evaluation

Source: gateway/image_evaluation.py · Python · 1 functions · 3 classes

Overview

Fail-closed Image Lab evaluation contract. Keeps evaluation separate from generation. A missing required scorer is an infrastructure failure, never a passing result.
