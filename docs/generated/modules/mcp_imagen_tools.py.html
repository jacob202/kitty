Overview

Tool registration — imports all tools so they're registered on the MCP server. PR 3 collapses the 4 legacy generate_image* tools into: - ``generate`` (unified, engine-dispatched, cached) - ``edit_image`` (unified, engine-dispatched) - ``batch_generate`` (parallel N prompts via asyncio.gather) The non-generation tools (refine, variations, avatar, reference, gallery) are unchanged in behavior but now live in their own modules.
