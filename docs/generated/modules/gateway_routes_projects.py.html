gateway.routes.projects

Source: gateway/routes/projects.py · Python · 13 functions · 3 classes

Overview

Project registry + resume endpoints (P6/P4, docs/packets/021 + 016). Sync handlers on purpose: refresh() blocks on git subprocess calls and an asyncio.run for the memory search, so FastAPI should run these in its worker pool, not the event loop (same reasoning as /state and /actions).

Dependencies

__future__, fastapi, gateway, gateway.push, gateway.sse, hashlib, logging, pydantic
