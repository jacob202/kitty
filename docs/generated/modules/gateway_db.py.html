def assert_schema_current(db_file: Path = KITTY_DB_FILE, migrations_dir: Path = DB_MIGRATIONS_DIR) -> None

Raise RuntimeError if any migration file on disk has not been applied. Call this after :func:`migrate` to assert the database is fully up to date. Fails loud — never silently swallows a missing migration.
