_mem0_llm_target sync complexity: moderate (6)

def _mem0_llm_target() -> dict[str, str]

Resolve Mem0 extraction through Kitty's live provider policy. Calling Kitty's full Gateway endpoint here would recurse through context assembly and memory search. Automatic mode therefore targets the isolated LiteLLM service directly. When Jacob pins an exact provider, Mem0 uses that provider's OpenAI-compatible base URL, key, and configured default model.
