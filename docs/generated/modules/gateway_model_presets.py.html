gateway.model_presets

Source: gateway/model_presets.py · Python · 9 functions · 1 classes

Overview

Curated, evidence-honest model picker payloads. The picker is a read-side view over Kitty's existing model-role policy and provider discovery snapshot. It is not a second model registry and it never promotes a discovered candidate into production routing.

Dependencies
