gateway.image_character_contracts

Source: gateway/image_character_contracts.py · Python · 9 functions · 1 classes

Overview

Executable Image Studio character contracts. The legacy character tables store names, photos, and gallery rows. They do not say how those photos condition a model. This module adds an owner-readable JSON contract beside each character and refuses generation when the selected engine cannot honor that contract exactly.

async def comfyui_character_runtime_status() -> tuple[bool, str]

Prove the exact SDXL adapter exists before a character job is created. The legacy readiness probe passed when *any* IP-Adapter model existed. Kitty was configured with an SD1.5 FaceID file while sending it an SDXL checkpoint, so a green readiness light did not mean the workflow was compatible.
