Source: gateway/memory_explain.py · Python · 4 functions · 0 classes

Overview

Read-only explanation projection over the governed explicit-memory store (#552). QoL Packet 04: for any significant remembered fact the user can ask *where did you get that?* and receive a truthful, id-addressable explanation — fact, source, source type, time, authority, confidence/truth status, superseded value, current state, sensitivity — without ever touching Kitty's memory internals. This module never mutates and never exposes embedding bytes; it composes ``explicit_memory`` only.
