gateway.activity_timeline

Source: gateway/activity_timeline.py · Python · 9 functions · 0 classes

Overview

Unified activity timeline — a read-only projection over existing evidence. Kitty's activity lives in several existing ledgers (Automation Run evidence, image jobs, explicit memory, signals, and approval/grants). This module merges them into one chronological view without introducing a new event store.
