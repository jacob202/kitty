mcp.imagen.cache

Source: mcp/imagen/cache.py · Python · 4 functions · 0 classes

Overview

SHA256-keyed cache for identical (prompt, engine, params) inputs. Refine loops that come back DONE on round 1 hit the cache for any re-runs. Identical prompts from different sessions dedup. The cache key is a hash (not the params blob) to keep filenames short. Cache invalidation: ``model_name`` is included in the key params, so when an engine version changes the cache is implicitly invalidated.

def key_for(prompt: str, engine: str, params: dict[str, Any]) -> str

Return a deterministic SHA256 hex digest for the given inputs. ``params`` should include ``model_name`` so engine version changes invalidate the cache. ``seed=0`` and ``seed=None`` produce different keys (tested explicitly).
