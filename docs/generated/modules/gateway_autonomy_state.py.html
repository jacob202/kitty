Overview

Autonomy State Layer for Kitty. Provides persistent memory of 'thinking' and tool execution history across long reasoning cycles (10+ turns).

def get_session(session_id: int) -> Optional[Dict[str, Any]]

Return the durable session row, or None when no such session exists. A session that has recorded no steps yet is still a real session. Callers must distinguish "no row" from "no history" or they report a freshly spawned agent as missing.

interrupt_active_sessions sync complexity: simple (2)

def interrupt_active_sessions() -> int

Mark sessions interrupted when no executor survived a Gateway restart. Live executor identity exists only in ``agent_runner._AGENT_TASKS``, which dies with the process. Any row still `active` at startup is therefore describing an executor that no longer exists. The update is conditional on the row still being `active`, which makes it idempotent and means it can never overwrite a terminal status that won a race against it. Recorded steps and partial output are never touched.

Example Usage (synthetic)

from gateway.autonomy_state import interrupt_active_sessions

result = interrupt_active_sessions()
# result: int
