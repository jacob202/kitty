scripts.resume

Source: scripts/resume.py · Python · 12 functions · 0 classes

Overview

Print a one-screen orientation block for the current Kitty worktree. Gathers branch state, open PRs, test-collection count, service health, the current blocking packet, local-only branches, and the most recent session note. No deps beyond the stdlib plus the `gh` and `git` CLIs. Run: `python3.12 scripts/resume.py` or `./kitty resume`.

Dependencies

__future__, concurrent.futures, datetime, json, os, pathlib, re, subprocess, sys

packet_state sync complexity: moderate (9)

def packet_state() -> tuple[str, list[str]]

Return (active_packet, blocked_packets). The packet registry uses ✓/📋/⛔/✏️ rather than a literal 🔄. We treat the first non-shipped, non-blocked row as "active" and any ⛔ row as "blocked". Falls back to "(none)" and [] when the file is missing.
