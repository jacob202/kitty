_load_recent_events sync complexity: simple (2)

def _load_recent_events(limit: int = 10) -> list[dict]

Load the most recent digest events from SQLite. Fails loud: a store error raises ModelDigestError instead of silently returning an empty list, so the morning brief can report the outage honestly rather than appearing to have "no model news".
