Overview

User feedback and error logging — owned substrate for the feedback endpoint. Why this module exists (Phase 3 of the gateway deepening program): the route handler used to swallow every I/O error with a bare ``except Exception: pass``, hiding real disk-write failures from the operator. The new module validates inputs, writes through ``paths.py``, and raises on failure so the route layer cannot mask a broken log. The wire shape of every endpoint that used to live in ``routes/feedback.py`` is unchanged. The route is now a thin request-parsing / response-shaping wrapper around these functions.

log_feedback sync complexity: simple (1)

def log_feedback(feedback: dict) -> None

Append one feedback record to ``FEEDBACK_LOG``. Raises on any I/O failure. The caller (the route layer) does not catch this — a write failure is a real, loud failure that the operator should see in the gateway log.
