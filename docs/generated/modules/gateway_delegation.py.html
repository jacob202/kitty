Source: gateway/delegation.py · Python · 7 functions · 0 classes

Overview

Delegation packet generator (P3, docs/packets/007). Turns an approved action into an executor-ready packet file under docs/packets/. No external calls, no process spawning — the output is a markdown file and nothing more.
