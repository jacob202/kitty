gateway.desktop_store

Source: gateway/desktop_store.py · Python · 11 functions · 0 classes

Overview

Desktop Phase 1 storage helpers. Keeps the Quick Capture inbox format stable so desktop and future mobile surfaces can write into the same append-only queue.

Dependencies

__future__, datetime, filelock, gateway.paths, json, os, pathlib, typing, uuid
