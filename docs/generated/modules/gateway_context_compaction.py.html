gateway.context_compaction

Source: gateway/context_compaction.py · Python · 3 functions · 0 classes

Overview

Context Compaction — auto-summarize long chat threads into memory checkpoints. When a conversation exceeds MESSAGE_THRESHOLD messages, the compaction system replaces the older messages with a single "Previously..." summary and persists a memory checkpoint via explicit_memory so the thread stays bounded while preserving narrative continuity.
