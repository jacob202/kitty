gateway.runpod_control

Source: gateway/runpod_control.py · Python · 2 functions · 8 classes

Overview

Narrow RunPod control-plane client for Kitty-managed image Pods. GPU Pod creation uses RunPod's GraphQL mutation because that API supports the cloud-enforced ``terminateAfter`` deadline used by the official RunPod CLI. Listing, inspection, deletion, and billing continue to use the REST API.
