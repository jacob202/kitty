gateway.model_routing

Source: gateway/model_routing.py · Python · 11 functions · 1 classes

Overview

Model routing truth — which provider each kitty-* alias actually calls. The aliases in litellm_config.yaml (kitty-default, kitty-small, …) are an indirection layer: app code names a *role*, the config names the provider. That only pays off if the mapping is inspectable. Before this module it wasn't — /api/models returned bare alias ids, so a dead OpenRouter balance looked identical to a healthy one from anywhere in the UI. Public API: describe_routing() -> dict
