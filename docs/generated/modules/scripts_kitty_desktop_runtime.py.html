scripts.kitty_desktop_runtime

Source: scripts/kitty_desktop_runtime.py · Python · 24 functions · 0 classes

Overview

Desktop Phase 1 runtime supervisor. Starts the Kitty gateway and kitty-chat UI if they are not already running, tracks pid files for desktop status, and writes a single desktop log.

Dependencies

__future__, argparse, json, os, pathlib, signal, socket, subprocess, sys, time, urllib.error, urllib.request
