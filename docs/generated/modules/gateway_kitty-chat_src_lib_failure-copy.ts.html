Overview

Translates a thrown fetch/query error into one short, plain-language sentence. Jacob does not code — raw strings like "Gateway returned 404 Not Found" name no cause and no action. This is the only place that translation happens; gateway.ts keeps returning the raw diagnostic form for anything that still needs it.
