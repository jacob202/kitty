gateway.automation_runs

Source: gateway/automation_runs.py · Python · 11 functions · 3 classes

Overview

Durable Automation Run evidence for scheduled and event-triggered actions. The run ledger records execution truth only. Schedule, monitor, signal, and other domain state remain owned by their existing stores.

Dependencies

__future__, gateway, gateway.paths, json, sqlite3, time, typing, uuid

retry_run sync complexity: simple (2)

def retry_run(run_id: str, started_at: float | None = None) -> dict[str, Any]

Mint a new running record reusing the original execution intent. The retried run receives a fresh identity and timestamps but preserves the original automation identity, action, trigger context, schedule reference, due-at, and parameters. Authorization is intentionally NOT copied; the dispatcher must re-evaluate it before re-invoking the action.
