Overview

Kitty ImageBench manifest, blind-review, and economics runner. This is deliberately not an image-generation engine. It sits above Kitty's existing ImagePlan/ImageJob/ImageEvaluation owners and turns completed image attempts into comparable evidence. Provider execution remains owned by ``gateway.image_runner``; this script performs no network or paid calls.
