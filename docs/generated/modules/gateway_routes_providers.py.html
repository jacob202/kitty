gateway.routes.providers

Overview

Active chat-provider inspection and switching. The streaming chat path goes through LiteLLM only (no provider fallback chain), so "which provider is Kitty using" is a property of ``gateway/litellm_config.yaml``. These routes read that file to report the active upstream and rewrite it to switch upstreams, then restart the launchd-managed LiteLLM service so the change takes effect. Switching is deliberately all-or-nothing across the four kitty-* models — a partial rewrite would leave the router in a state nobody designed for.
