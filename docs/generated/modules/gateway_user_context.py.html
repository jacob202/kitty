Source: gateway/user_context.py · Python · 7 functions · 0 classes

Overview

User identity context — loads Jacob's TELOS files for prompt injection. This is the counterpart to ``config/SOUL.md`` (which defines who *Kitty* is): ``config/USER/*.md`` describes who *Jacob* is — mission, goals, problems, beliefs, wisdom, projects, mental models, narratives. Files ship as templates carrying a ``TEMPLATE:`` marker line. A file is only included once that marker is removed (i.e. once Jacob has actually filled it in), so an unconfigured checkout injects nothing. Public API: load_user_context() -> str Compact "About Jacob (TELOS)" block, or "".
