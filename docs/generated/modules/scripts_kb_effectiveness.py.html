scripts.kb_effectiveness

Source: scripts/kb_effectiveness.py · Python · 27 functions · 2 classes

Overview

Record and report whether the cross-tool KB improves engineering outcomes. Receipts are hash-chained append-only evidence. This module never mutates KittyBuilder, opens issues, changes the roadmap, or claims causation from a correlation. Unknown measurements remain null rather than being converted into reassuring zeroes.

def session_total_tokens(session_id: str, root: Path | None = None) -> int | None

Read what this session actually cost from its own Claude Code transcript. The transcript is the provider's own accounting, so a receipt no longer depends on an agent remembering to type a number it cannot see. A session with no transcript on this machine stays null rather than becoming zero.
