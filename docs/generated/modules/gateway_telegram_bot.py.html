gateway.telegram_bot

Source: gateway/telegram_bot.py · Python · 7 functions · 0 classes

Overview

Telegram bot bridge — mobile access to Kitty via Telegram. Uses the Telegram Bot API directly (no extra dependencies). Polling-based: calls getUpdates in a loop, routes messages through Kitty's LLM pipeline, and sends responses back. Public API: start_polling() -> asyncio.Task Start background polling loop send_message(chat_id, text) -> bool is_configured() -> bool stop() Env: TELEGRAM_BOT_TOKEN
