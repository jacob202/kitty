_participant sync complexity: simple (1)

def _participant() -> str

Return the declaring participant, or refuse to guess one. This used to fall back to "chatgpt", which silently filed one agent's claim under another agent's name. The damage is delayed and confusing: the real agent then cannot commit, because its own mutation is checked against a lease it never held. Identity is authority here, so an unset identity must stop the mutation instead of borrowing a name.

_retire_session_binding sync complexity: simple (2)

def _retire_session_binding(context: dict[str, Any], session_id: str) -> None

Drop this worktree's binding once the session it names is gone. The env override used to skip this entirely, so a release performed with KITTY_AGENT_SESSION_ID exported left the binding file pointing at a released session. The next command to read the file then failed against a lease that no longer existed. Unlinking only when the file names the session being retired is safe regardless of where that session id came from.
