gateway.brief_scheduler

Source: gateway/brief_scheduler.py · Python · 5 functions · 0 classes

Overview

Morning Brief configuration and delivery. Calendar timing is owned by :mod:`gateway.cron`; this module only reads the user's local-clock preference and performs the Brief delivery action.

Dependencies
