mcp.imagen.face_match

Source: mcp/imagen/face_match.py · Python · 2 functions · 8 classes

Overview

Reusable exact-reference face matcher for the character benchmark. Unlike ``verify.score_face_match`` (which globs an entire reference directory and re-initializes InsightFace per call), this matcher scores a generated image against exactly one reference embedding — the character's locked reference — and initializes InsightFace once per benchmark run. Fails closed: any missing dependency, undecodable reference, or reference with no detectable face raises ``FaceScorerUnavailable`` rather than returning a neutral or passing score.
