Overview

Pydantic-settings model for Kitty gateway configuration. All env vars the gateway reads are declared here. Call ``get_settings()`` (never import the Settings class directly) to get a fresh instance that re-reads from the current os.environ, which keeps pytest monkeypatch working.

Dependencies
