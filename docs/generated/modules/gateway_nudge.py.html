Overview

Proactive Nudge Engine — detect patterns and suggest actions without being asked. Triggers: - Repeated research: same topic 3x without action → nudge - Dropped threads: topic mentioned then silence → check-in - Milestones: first completed build, health streak → celebrate - Time-based: calendar gap → suggest activity Public API: check() -> list[dict] Run all nudge checks, return active nudges check_with_status() -> dict Run checks with per-source failure reporting dismiss(nudge_id) -> bool get_pending() -> list[dict]

_PartialFailure

Raised by a detector when some sub-checks succeed and others fail. Carries the nudges from successful sub-checks so callers can return partial results while reporting degraded status.
