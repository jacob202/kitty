Overview

The deliberately small tool surface Kitty hands to Open WebUI. Open WebUI turns every operation in an OpenAPI document into a model tool. The Gateway's full schema contains hundreds of operations, so this router exposes only bounded, user-facing projections. Reads must stay read-only: a chat tool must never initialize, migrate, or repair a control-plane store as a side effect. Mounted under ``/tools/v1`` and protected by the Gateway bearer secret.
