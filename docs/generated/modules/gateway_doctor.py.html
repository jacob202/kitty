gateway.doctor

Source: gateway/doctor.py · Python · 34 functions · 1 classes

Overview

Kitty preflight / health doctor. Checks the real stack: gateway, LiteLLM, ChromaDB, mem0, Telegram token, disk space, venv. Exits non-zero when any required check fails. Usage: python gateway/doctor.py # human-readable table python gateway/doctor.py --json # JSON output python gateway/doctor.py --strict # fail on WARN too

_check_env_parse sync complexity: moderate (9)

def _check_env_parse(dotenv: pathlib.Path) -> list[Check]

Flag .env lines that python-dotenv can't parse. Every python-dotenv consumer prints "could not parse statement starting at line N" per bad line per process — a stray quote on line 1 spammed nine warnings per `kitty` command live on 2026-07-05. This names the exact lines so the fix is a 10-second edit instead of a mystery.
