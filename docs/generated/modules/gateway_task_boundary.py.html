gateway.task_boundary

Source: gateway/task_boundary.py · Python · 0 functions · 1 classes

Overview

Task Boundary System — Antigravity-style task tracking and progress reporting. This module implements structured task boundaries that group agent actions into named tasks with progress summaries, similar to Antigravity's task_boundary tool.
