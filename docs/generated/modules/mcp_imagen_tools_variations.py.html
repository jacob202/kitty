def variations(image_path: str, count: int = 3) -> list

Produce several alternates of an existing image — same subject, varied pose, angle, and lighting. Good for "give me more like this one." Args: image_path: Absolute path to the source image. count: How many variations (1-4). Default 3. Returns: Each variation (inline) plus its saved path.
