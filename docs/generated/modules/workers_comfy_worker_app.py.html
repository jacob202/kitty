_installed_bundles sync complexity: simple (3)

def _installed_bundles(root: Path) -> list[WorkflowBundle]

Load every workflow bundle installed under *root*, in id order. A directory that looks like a bundle but fails to load raises rather than being skipped: a silently dropped bundle reads downstream as "not installed", which is the same signal as a deliberate omission.
