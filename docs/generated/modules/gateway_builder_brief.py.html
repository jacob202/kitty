gateway.builder_brief

Source: gateway/builder_brief.py · Python · 4 functions · 0 classes

Overview

KittyBuilder Phase 1B — worker brief renderer. Turns a queue task into a complete, self-contained worker prompt: scope, acceptance criteria, branch, validation, fencing rules, and stop conditions. Pure presentation — no DB access, no side effects. The CLI feeds it the task dict, its events, and its PR links.
