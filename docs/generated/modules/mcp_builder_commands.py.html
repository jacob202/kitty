mcp.builder.commands

Source: mcp/builder/commands.py · Python · 18 functions · 0 classes

Overview

Governed KittyBuilder mutation adapters for MCP clients. Every operation delegates to an existing Builder authority. This module owns no queue/run state and exposes no arbitrary shell or Git command surface.

Dependencies
