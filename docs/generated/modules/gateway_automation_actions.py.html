gateway.automation_actions

Source: gateway/automation_actions.py · Python · 8 functions · 6 classes

Overview

One named Automation action registry and execution path. Time, signal, monitor, and manual triggers all dispatch through this module. Authorization is delegated to the existing action_grants policy engine; callers cannot supply their own tier or approval outcome.
