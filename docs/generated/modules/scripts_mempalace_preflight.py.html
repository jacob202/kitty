Overview

MemPalace preflight — prove the installed package before you trust it. The MemPalace adapter (`gateway/mempalace_adapter.py`) and the migration script were written WITHOUT a MemPalace package available to test against. This script is the safety net: run it first, on your machine, with `mempalace` installed. It confirms the read path the adapter depends on and surfaces the real CLI subcommand names you'll need for ingestion — so nothing downstream is a guess. Read-only by default (never writes to your store). Usage: pip install mempalace python scripts/mempalace_preflight.py Exit code 0 = the search/read path is verified. Non-zero = fix before migrating.
