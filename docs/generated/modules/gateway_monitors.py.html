gateway.monitors

Source: gateway/monitors.py · Python · 6 functions · 3 classes

Overview

URL/page monitors — owned substrate for the monitors endpoint. Why this module exists (Phase 3 of the gateway deepening program): the route used to keep a parallel in-memory ``_monitors`` list and swallow every ``ImportError`` / ``AttributeError`` from ``gateway.web_monitor`` with a try/except that fell back to the mock. That violated the "Fail loud" prime directive. The new module delegates to ``web_monitor`` (the real, SQLite-backed store) and lets its exceptions surface.

Dependencies
