Overview

Reasoning engine — complexity classifier, model routing, execution receipts. Part C of packet 028: the per-message optimization layer. Classification is a pure heuristic (<1ms), never a model call. Routing selects only among existing LiteLLM aliases — no new aliases, no provider changes.

def classify_complexity(message: str, domain: str | None = None) -> Classification

Classify a user message without calling a model. Pure heuristic, <1ms. The keyword sets absorbed from ``gateway/llm_client.py`` are one signal among several. Returns ``Classification(tier, trigger)`` where ``trigger`` names the signal that decided.
