_projected_attempt_cost_cad sync complexity: simple (1)

def _projected_attempt_cost_cad(governor_route: str, worker_model: str, reviewer_model: str) -> float

Project one paid attempt from the *configured* model slugs. The worker pass keeps the governor's tier-sized token shape but is priced at the configured ``worker_model`` — not at the governor's hard-coded route model — so swapping the worker slug in the paid route config changes the projection. An unpriced slug is an error rather than a free ride: a silent zero would understate the spend-ceiling check below.
