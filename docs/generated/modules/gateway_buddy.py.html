Overview

Buddy state — Kitty's persistent mood, energy, and session counters. The UI polls GET /mood to get the current state instead of guessing from message text. State survives across requests in memory and is snapshotted to data/kitty/buddy_state.json on every write so it survives restarts. Mood transitions: idle — base state, no recent activity thinking — set when a request starts success — set when a response completes cleanly confused — set when an error or drift violation occurs searching — set when context retrieval is in progress
