scripts.agent_council

Source: scripts/agent_council.py · Python · 6 functions · 2 classes

Overview

Run bounded, read-only opinions from local coding-agent CLIs. The persistent Kitty/Letta agent can invoke this for an explicit ``council:`` request. Each worker is isolated as a subprocess and receives the same prompt; the caller remains responsible for synthesis and any later mutation.
