Source: gateway/token_usage_log.py · Python · 2 functions · 0 classes

Overview

Thread-safe JSONL token telemetry to data/kitty_token_log.jsonl. Schema (one object per line), aligned with AGENTS.md: ts, date, provider, model, operation, usage, metadata ``usage`` uses API-native prompt_tokens / completion_tokens / total_tokens when present.

Dependencies

__future__, datetime, gateway.paths, json, logging, threading, time, typing
