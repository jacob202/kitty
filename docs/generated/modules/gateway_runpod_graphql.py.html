gateway.runpod_graphql

Source: gateway/runpod_graphql.py · Python · 1 functions · 3 classes

Overview

Minimal RunPod GraphQL support for GPU Pod creation. RunPod's current official CLI uses GraphQL for GPU Pod creation because the GraphQL input supports cloud-enforced ``terminateAfter``. All other Kitty Pod operations remain on the documented REST control plane.
