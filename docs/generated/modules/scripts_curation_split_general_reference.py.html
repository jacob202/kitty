scripts.curation.split_general_reference

Source: scripts/curation/split_general_reference.py · Python · 8 functions · 0 classes

Overview

Split the 'general reference' KB into focused knowledge bases. Reads filenames from the DB, classifies them by pattern matching, creates new KBs as needed, and moves files via the Open WebUI API.

Dependencies

__future__, argparse, logging, pathlib, re, requests, sqlite3, time
