gateway.session_end_audit

Source: gateway/session_end_audit.py · Python · 8 functions · 3 classes

Overview

Read-only proof that OpenCode actually executed the session-end contract. A skill file or duplicate-skill warning is not execution evidence. This audit uses Kitty's canonical hash-chain receipt parser and workflow-signal parser, then requires both records to describe the same Builder-owned OpenCode session.
