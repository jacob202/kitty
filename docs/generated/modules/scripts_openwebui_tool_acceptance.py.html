verify_features sync complexity: complex (13)

def verify_features(accept_charges: bool = False) -> dict[str, object]

Verify the configured daily-driver surface, then optionally prove paid routes. The default pass is read-only and does not invoke an LLM. With ``accept_charges=True`` it also performs one tiny completion through each user-facing model route and one end-to-end turn through Daily Kitty.

Example Usage (synthetic)
