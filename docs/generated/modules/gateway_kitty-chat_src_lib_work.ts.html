postCommandResult function

async function postCommandResult(endpoint: string, body: unknown, timeoutMs = DEFAULT_TIMEOUT_MS)

The command and tick routes answer 200 with {ok:false, error} for refusals the operator must see (task not found, initiative already running). Treating a non-200 as the only failure would report those refusals as success, so the body is the authority and transport failure is folded into the same shape.
