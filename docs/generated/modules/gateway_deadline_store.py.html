claim_escalation sync complexity: simple (2)

def claim_escalation(deadline_id: int, checkpoint: str) -> bool

Atomically claim an escalation checkpoint for delivery. Returns True if this caller won the claim, False if already claimed/completed. Uses a unique constraint on (deadline_id, checkpoint, claimed=1) to ensure only one concurrent caller can hold the claim.
