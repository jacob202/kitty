mcp.imagen.engines

Source: mcp/imagen/engines/__init__.py · Python · 3 functions · 0 classes

Overview

Engine registry — maps engine slugs to engine instances. Adding a new engine: implement the Engine protocol, add an entry here. The tool layer dispatches by name via ``registry.get(engine_name)``.
