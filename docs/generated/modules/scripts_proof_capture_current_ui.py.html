scripts.proof_capture_current_ui

Source: scripts/proof_capture_current_ui.py · Python · 6 functions · 0 classes

Overview

Capture current Kitty UI evidence from an isolated proof worktree. This script performs no provider/model calls and does not mutate Builder state. It replaces only an invalid node_modules symlink inside the current worktree, installs the pinned frontend dependencies, builds the UI, starts the production server, and captures Home/Work evidence at desktop and phone viewports.
