gateway.domain_router

Source: gateway/domain_router.py · Python · 3 functions · 0 classes

Overview

Domain classifier — keyword scorer over the user message. Returns one of: soul | repair | health | research | code. Used by context_assembler to pick the system-prompt file and by routes to pick the LLM model route.
