gateway.patterns

Source: gateway/patterns.py · Python · 5 functions · 0 classes

Overview

Longitudinal Pattern Tracking — multi-timeframe behavioral analysis. Builds on honcho.py for weekly mirrors, extends to monthly/quarterly/annual perspectives. Detects productivity cycles, mood seasons, recurring frustrations. Public API: analyze(days) -> dict Analyze patterns over N days weekly() -> dict Weekly pattern summary annual_review() -> dict Year-over-year perspective
