gateway.context_references

Source: gateway/context_references.py · Python · 7 functions · 1 classes

Overview

Resolve durable object references embedded invisibly in chat messages. The composer persists stable refs as HTML comments so retries/reloads keep the same identity while the visible user message stays readable. This module is a read-only projection: ProjectStore, ArtifactStore, and chats_store remain the owners of the referenced objects.
