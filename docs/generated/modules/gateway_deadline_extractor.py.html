gateway.deadline_extractor

Source: gateway/deadline_extractor.py · Python · 7 functions · 1 classes

Overview

Deadline extraction from health/admin documents and mail signals (P7, docs/packets/017). Extraction runs through the shared cloud model route. ADR 0022 retired the D10 local-only boundary, so this content reaches a cloud provider like any other. Callers provide an injected `llm_fn` for tests. Public API: extract_from_text(text, *, source, source_id=None, llm_fn=None) -> list[dict] extract_from_document(source, text, *, llm_fn=None) -> list[dict] extract_from_mail_signal(signal, *, llm_fn=None) -> list[dict]
