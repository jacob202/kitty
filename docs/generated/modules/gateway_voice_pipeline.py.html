gateway.voice_pipeline

Source: gateway/voice_pipeline.py · Python · 2 functions · 7 classes

Overview

Voice Pipeline — deep module for real-time voice conversation. This is a DEEP module. Callers should only use: - VoicePipeline.process_turn(audio_bytes) -> VoiceTurnResult: The high-leverage entry point. - VoicePipeline.handle_websocket(ws): WebSocket handler for voice sessions. Internal adapters (STT, TTS, gate) are implementation details.
