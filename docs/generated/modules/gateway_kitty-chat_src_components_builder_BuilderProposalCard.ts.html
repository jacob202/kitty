friendlyMutationError function

function friendlyMutationError(err: unknown, fallback: string)

gateway.ts's describeFetchError already turns an HTTP error status into "Gateway returned <status> <statusText>", but when the browser can't reach the gateway at all (connection refused, DNS failure), fetch() itself throws with the browser's own message — Chromium's is the literal string "Failed to fetch", which is not something a non-technical user can act on.
