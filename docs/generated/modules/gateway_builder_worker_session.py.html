gateway.builder_worker_session

Source: gateway/builder_worker_session.py · Python · 0 functions · 3 classes

Overview

Canonical Builder worker event and runtime-state vocabulary. The abandoned WorkerSession backend abstraction was removed; production worker execution is owned directly by builder_runner/builder_runtime. This module keeps only the shared event/state types consumed by the cockpit and runtime projection.

Dependencies
