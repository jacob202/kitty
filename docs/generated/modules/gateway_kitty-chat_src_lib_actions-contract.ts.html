Overview

** OK-ACTION-01 — Shared Object + Action Contract The smallest reusable product contract that lets Kitty render the same owned object with the same meaningful actions across Home, Chat, Work, Projects, Library, Automations, and Image Lab without introducing a new source of truth. This contract is a projection layer only. Existing per-authority responses remain authoritative.
