Overview

Fal engine — REST image generation via fal's async queue API, FLUX PuLID. Fal's queue endpoint (``https://queue.fal.run/<model>``) is asynchronous: submit a request, poll its status until ``COMPLETED``, then fetch the result (a list of image URLs) and download the bytes. Auth is ``Authorization: Key <FAL_KEY>`` (not ``Bearer``). The configured PuLID model requires exactly one reference image. Paid Fal submissions are intentionally at-most-once from Kitty: once the provider has accepted a request, polling/result/download failures must never cause a second paid generation to be submitted automatically.
