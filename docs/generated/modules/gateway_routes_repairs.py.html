gateway.routes.repairs

Source: gateway/routes/repairs.py · Python · 9 functions · 0 classes

Overview

Self-repairs endpoint — actionable diagnosis for chat and Home cards. Every repair item has a plain-English title, severity, and optional fix button that dispatches through the action queue at T0 (auto-execute, logged).
