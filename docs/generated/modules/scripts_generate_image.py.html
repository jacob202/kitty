Overview

Generate an image via the gateway's ComfyUI-backed endpoint. Used by the /image-gen skill. Model/style selection from keywords ("portrait", "sdxl", "explicit", etc.) happens server-side in gateway/image_gen.py — this script just checks availability, submits the prompt, and reports the result.
