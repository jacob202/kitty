gateway.chronicle_service

Source: gateway/chronicle_service.py · Python · 13 functions · 0 classes

Overview

Pure session-history analysis for the chronicle feature. All functions here are side-effect-free: they accept raw chat dicts and return structured data. No FastAPI or storage dependencies live in this module — that makes the logic independently testable and reusable.

Dependencies

__future__, collections, datetime, re, typing
