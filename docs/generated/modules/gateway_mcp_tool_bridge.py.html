gateway.mcp_tool_bridge

Source: gateway/mcp_tool_bridge.py · Python · 16 functions · 1 classes

Overview

MCP Tool Bridge — runtime discovery and bounded tool invocation. This module deliberately owns only the transport/lifecycle seam. Kitty's standing authorization policy remains in :mod:`gateway.action_grants`. Circuit state is process-local load-shedding state, not durable product truth.

Dependencies

__future__, asyncio, dataclasses, gateway.paths, gateway.plugin_registry, json, logging, math, threading, time, typing
