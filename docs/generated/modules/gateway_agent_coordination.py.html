gateway.agent_coordination

Source: gateway/agent_coordination.py · Python · 29 functions · 1 classes

Overview

KX-COORD-01: SQLite-enforced mutation ownership for Kitty agents. SQLite is authoritative for ownership. The tracked semantic registry defines claimable resources; GAR is a best-effort event projection only.

Dependencies

__future__, datetime, fnmatch, gateway, gateway.paths, json, pathlib, sqlite3, subprocess, time, typing, uuid, yaml
