Source: gateway/routes/loops.py · Python · 6 functions · 0 classes

Overview

Loops endpoint for Kitty UI — background task loops. Backed by gateway.cron so the UI surface shows real scheduled tasks instead of hard-coded demo rows.

Dependencies
