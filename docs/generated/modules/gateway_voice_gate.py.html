Source: gateway/voice_gate.py · Python · 5 functions · 1 classes

Overview

Voice Gate — pre-response filter enforcing SOUL.md compliance before user sees output. Two layers: - filter(response_text) -> cleaned_text: Strip banned phrases, return clean + drift report. - check(text) -> VoiceGateResult: Inspect without modifying (for streaming or logging). The gate runs BEFORE any response reaches the user. If drift is detected, the response is cleaned and the incident is logged to self_review for pattern tracking.
