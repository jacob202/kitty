scripts.curation.assign_kb_files

Source: scripts/curation/assign_kb_files.py · Python · 7 functions · 0 classes

Overview

Categorize uploaded Open WebUI files and assign them to knowledge bases. Creates missing KBs, then POSTs each file to the correct KB (which triggers embedding into ChromaDB). Runs in parallel batches for speed. Usage: python scripts/assign_kb_files.py python scripts/assign_kb_files.py --dry-run python scripts/assign_kb_files.py --workers 4
