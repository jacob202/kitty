gateway.operating_policy

Source: gateway/operating_policy.py · Python · 23 functions · 2 classes

Overview

Executable operating contracts for model roles, image characters, and Builder. A label, database row, or green unit test is not a working product. These validators require the operating decisions and evidence needed to support the claim a role, character, or Builder campaign makes.
