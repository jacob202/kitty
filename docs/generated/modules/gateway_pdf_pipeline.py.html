Overview

Phase 9 PDF pipeline — LlamaCloud primary, PyMuPDF fallback. Inline image vision is opt-in because the main knowledge pipeline already has a separate vision-enrichment stage for manuals and other high-value PDFs.

extract_pdf_enhanced sync complexity: simple (3)

def extract_pdf_enhanced(path: Path) -> list[PdfChunk]

Extract text and images from a PDF. Returns one PdfChunk per logical page/section. Strategy: 1. Try LlamaCloud parsing (if LLAMA_CLOUD_API_KEY set) — structured markdown output 2. Fall back to PyMuPDF → pdfplumber for plain text 3. Inline image vision is off by default; use the knowledge pipeline's separate vision enrichment stage for manuals / high-value scans.
