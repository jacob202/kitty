# Autonomy v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Harden KittyBuilder so unattended execution reconciles truth, refuses stale/invalid work cheaply, measures runway, and surfaces refill/publication decisions without widening authority.

**Architecture:** Extend the existing Builder supervisor and immutable packet contract; add one focused read-only autonomy projection module. The queue remains authoritative and launchd remains the only scheduler.

**Tech Stack:** Python 3.12+, SQLite, pytest, git/gh CLI.

**Spec:** `docs/superpowers/specs/2026-08-31-autonomy-v2-design.md`

## Global Constraints
- No auto push, PR create, merge, retry grant, paid route, or second scheduler.
- External reconciliation is read-only and fail-visible.
- Tests must fail before production changes.
