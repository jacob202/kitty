# Capability Manifest

The full Capability Manifest design specification has moved to
[`docs/contracts/CAPABILITY_MANIFEST.md`](contracts/CAPABILITY_MANIFEST.md).

It is a **proposed design contract and schema**, not current runtime truth.
ADR 0029 ratifies the principle that Kitty will have one capability manifest
as the single source of runtime truth; ADR 0032 ratifies evidence-backed
claims; Constitution v1 Article III.5 ratifies honest state. The detailed v2
schema in the contract has not been ratified or built.

For **actual current runtime behavior**, see `gateway/runtime_manifest.py`
and `gateway/builder_status.py`. This pointer exists so historical references
to `docs/CAPABILITY_MANIFEST.md` keep resolving.
