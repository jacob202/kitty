# ONE KITTY — Reference Research Notes

These notes support the theft ledger and packets. They intentionally capture interaction principles rather than prescribing literal clones.

## Raycast

- Action Panel is contextual to the selected item.
- Primary action is first; secondary actions are grouped.
- Actions are searchable and shortcuts are visible.
- AI Extensions let Chat operate across existing extension tools; explicit `@` mentions scope the assistant; tool confirmation can remain enabled.

Kitty lesson: the same object/action vocabulary can serve direct manipulation and Chat without moving authority into Chat.

## Linear

- Command menu groups/prioritizes actions based on current focus/view.
- Contextual menus expose underlying object operations close to where invoked.
- Linear explicitly optimizes tiny repeated interaction costs such as submenu pointer paths.
- Inbox surfaces attention and allows action on the underlying issue, plus snooze/read controls and keyboard traversal.

Kitty lesson: Home attention should terminate in underlying object actions, and visual sophistication includes interaction micro-precision.

## Anthropic / Claude

- Anthropic uses a recognizable family of simple editorial illustrations and organic motifs around a comparatively calm product/brand presentation.
- Claude Design emphasizes applying a design system consistently to keep outputs on-brand.

Kitty lesson: define a restrained illustration family and use it selectively after the product geometry is coherent. Do not imitate Claude assets/style directly.
