# OK-PRECISION-LIBRARY-AUTOMATIONS — Library + Automations Precision Migration

## Mission

Apply shared precision primitives to Library/Artifact Canvas and Automations while keeping canonical artifacts and schedule truth dominant.

## Depends on

- `OK-PRECISION-01`
- accepted Artifact Canvas and Automations implementations

## Scope

- Library list rows/search/filter controls
- Artifact Canvas chrome
- Automation schedule/routine rows
- status/action alignment
- empty/loading/degraded states
- phone composition

## Acceptance

- artifact/schedule rows share coherent object-row grammar without becoming identical domain components;
- search/refresh/actions meet touch and keyboard rules;
- derived Knowledge remains subordinate to canonical artifacts;
- failed indexing never visually removes saved artifacts;
- failed Automation read never looks like empty schedule list;
- no squeezed tables/horizontal scroll on phone;
- Artifact Canvas controls match common action geometry.

## Non-goals

- Artifact storage changes;
- new scheduler model;
- new preview types.
