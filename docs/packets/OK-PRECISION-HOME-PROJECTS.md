# OK-PRECISION-HOME-PROJECTS — Home + Projects Precision Migration

## Mission

Migrate Home and Projects to the shared precision contract after their product behavior is settled, eliminating local geometry drift without flattening valid domain differences.

## Depends on

- `OK-PRECISION-01`
- `OK-HOME-01`
- accepted Project Workspace foundation

## Scope

- Home action board typography/spacing/row anatomy
- Project list/workspace typography/spacing
- shared title/action baselines
- object rows, status, buttons, empty/loading/error states
- phone composition

## Acceptance

- Home and Projects use the same title/body/metadata/control roles;
- primary actions occupy predictable positions;
- project/home object rows share coherent padding and status anatomy;
- no arbitrary tiny labels/mono text in primary hierarchy;
- no equal-weight card grid regression on Home;
- mobile is one intentional vertical flow with no horizontal scroll;
- changing state does not visibly jump major geometry.

## Non-goals

- changing Home ranking;
- replacing Project authority;
- mascot rollout.
