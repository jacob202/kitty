# OK-PRECISION-SETTINGS — Settings Precision Migration

## Mission

Apply the shared precision system to Settings so ordinary preferences read as product settings and technical/provider configuration remains truthful but subordinate.

## Depends on

`OK-PRECISION-01`.

## Scope

- section hierarchy
- labels/descriptions/control alignment
- appearance/personal preference geometry
- advanced/provider disclosures
- destructive/security-sensitive controls
- phone vertical flow

## Acceptance

- personal/product preferences appear before infrastructure mechanics;
- labels and controls share predictable rows/baselines;
- advanced sections are disclosed rather than permanently dense;
- secrets are never exposed;
- phone never squeezes desktop tables/path controls;
- destructive actions are unmistakable and appropriately confirmed;
- control states are readable without color alone.

## Non-goals

- provider architecture changes;
- secret management rewrite;
- new settings solely for visual customization unless already product-approved.
