# OK-PRECISION-WORK-ACTIVITY — Work + Activity Precision Migration

## Mission

Apply the shared precision system to Work and Activity so durable execution state is dense, legible, and consistent without exposing operator internals by default.

## Depends on

- `OK-PRECISION-01`
- accepted Activity Center/Work foundations

## Scope

- Work group/list anatomy
- Activity item anatomy
- status and duration alignment
- primary/secondary action placement
- details disclosure
- phone Work/Builder composition where applicable

## Acceptance

- Needs you / In progress / Completed hierarchy is obvious;
- status text + icons align consistently;
- running items do not jump layout as durations/status change;
- raw IDs/logs remain behind disclosure;
- list rows use body typography rather than terminal styling;
- phone avoids squeezed desktop cockpit;
- Activity and Work feel related while preserving their different purposes.

## Non-goals

- activity projection redesign;
- Builder execution logic;
- new monitoring store.
